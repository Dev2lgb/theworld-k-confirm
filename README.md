# K-자격 수강신청 관리 시스템 — 확인 요청서

사단법인 더월드에 드리는 확인 요청서를, 화면에서 바로 체크하고 입력할 수 있는 형태로 만든 것입니다.
답변은 서버에 파일로 쌓이고, 별도의 화면에서 문서 그대로 확인합니다.

## 화면

| 주소 | 쓰임 |
|---|---|
| `/` | 클라이언트가 작성하는 확인 요청서 |
| `/list.html` | 받은 답변 목록 |
| `/?id=<문서번호>` | 답변 하나를 문서 그대로 보기 (읽기 전용) |

## 어떻게 돌아가는가

1. 클라이언트가 요청서를 열어 네모를 누르고 빈칸에 적습니다.
2. 적는 대로 브라우저에 저장되고, 2.5초 뒤 서버로도 올라갑니다. 창을 닫을 때도 한 번 더 보냅니다.
3. 답변은 Vercel Blob 에 `answers/<문서번호>.json` 파일로 저장됩니다. 같은 사람이 다시 적으면 그 파일이 갱신됩니다.
4. 받는 쪽은 `/list.html` 에서 누가 어디까지 적었는지 보고, 눌러서 문서 그대로 읽습니다.
5. 클라이언트가 같은 브라우저로 다시 들어오면 서버에 있는 자기 답변을 불러와 이어서 씁니다.

따로 파일을 주고받지 않습니다.

## API

| 경로 | 하는 일 |
|---|---|
| `POST /api/save` | 답변 한 건을 파일로 저장 (덮어쓰기) |
| `GET /api/get?id=` | 답변 한 건 읽기. 없으면 `{"empty":true}` |
| `GET /api/list` | 저장된 답변 목록 |

`api/save.js` 는 문서번호 형식, 항목 이름, 글자 수, 전체 용량(400KB)을 검사한 뒤 저장합니다.

## 입력 항목

| 종류 | 개수 |
|---|---|
| 선택(체크박스) | 252 |
| 서술 입력칸 | 60 |
| 표 입력칸 | 25 |
| 문항 | 62 |
| 장 | 10 |

## 원본에서 바뀐 점

원본 `K-자격 확인요청서 (standalone).html` 은 한글 웹폰트 655개가 통째로 박혀 있어 **14.9MB** 였습니다.
폰트를 Google Fonts CDN 으로 돌리고 정적인 □ 와 밑줄을 실제 입력 요소로 바꿔 **288KB** 가 되었습니다.

## 배포

```bash
npx vercel login          # 한 번만
npx vercel link
npx vercel blob store add answers   # Blob 저장소 연결
npx vercel deploy --prod
```

Blob 저장소를 프로젝트에 연결하면 `BLOB_READ_WRITE_TOKEN` 이 자동으로 들어갑니다.

## index.html 다시 만들기

원본 번들 파일이 있는 상태에서:

```bash
python3 tools/transform.py <작업디렉터리>          # 본문 추출 + 입력 요소 변환
python3 tools/build.py     <작업디렉터리> index.html   # head/tail 틀과 합치기
```

이번 회차에서 빼기로 한 문항은 `tools/transform.py` 의 `DROP` 목록에 번호로 적혀 있습니다.
번호를 넣으면 그 문항이 통째로 빠지고 같은 장의 뒷 번호가 앞으로 당겨지며, 지우면 되살아납니다.

`tools/head.html` 은 상단 바와 css, `tools/tail.html` 은 저장·진행률·보기 모드 스크립트입니다.
문구나 동작을 고칠 때는 `index.html` 이 아니라 이 두 파일을 고치고 다시 만드십시오.
