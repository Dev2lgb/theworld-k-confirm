# K-자격 수강신청 관리 시스템 — 확인 요청서

사단법인 더월드에 드리는 확인 요청서를, 화면에서 바로 체크하고 입력할 수 있는 형태로 만든 것입니다.

## 보시는 곳

https://dev2lgb.github.io/theworld-k-confirm/

## 답변을 받는 방법

1. 클라이언트가 위 주소를 열어 네모 칸을 누르고 빈칸에 내용을 적습니다.
2. 적은 내용은 브라우저에 자동 저장되므로, 여러 번에 나누어 작성해도 됩니다.
3. 화면 위쪽 **답변 파일 저장**을 누르면 `K자격_확인요청서_이름_날짜.json` 파일이 내려받아집니다.
4. 그 파일을 메일이나 메신저로 받으면 됩니다.
5. 받은 파일은 같은 화면의 **불러오기** 로 다시 열어 볼 수 있습니다.

json 파일에는 항목별 응답과 함께, 사람이 바로 읽을 수 있는 `summary` 문자열이 들어 있습니다.

## 입력 항목

| 종류 | 개수 |
|---|---|
| 선택(체크박스) | 255 |
| 서술 입력칸 | 61 |
| 표 입력칸 | 25 |
| 문항 | 63 |
| 장 | 10 |

## 원본에서 바뀐 점

- 원본 `K-자격 확인요청서 (standalone).html` 은 한글 웹폰트 655개가 통째로 박혀 있어 **14.9MB** 였습니다.
- 폰트를 Google Fonts CDN 으로 돌리고 정적인 □ 와 밑줄을 실제 입력 요소로 바꿔 **292KB** 가 되었습니다.

## 다시 만들기

원본 번들 파일이 있는 상태에서:

```bash
python3 tools/transform.py <작업디렉터리>   # 본문 추출 + 입력 요소 변환
python3 tools/build.py <작업디렉터리> index.html
```
